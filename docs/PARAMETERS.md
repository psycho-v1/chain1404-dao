# Launch parameters

Changing a row after go-live is itself a critical (or consensus) proposal.

| Parameter | Suggested initial value | Change class |
| --- | --- | --- |
| Epoch length | 7 days | Critical |
| Miner / staker combined weight | 70 / 30 | Critical |
| Ordinary quorum | 15% miner, 10% staker | Critical |
| Critical quorum | 20% miner, 15% staker | Critical |
| Ordinary chamber floor | 40% yes in each chamber | Critical |
| Ordinary weighted score | > 50% | Critical |
| Critical weighted score | >= 60% and majority in both chambers | Critical |
| Ordinary timelock | 72 hours | Critical |
| Critical timelock | 7 days | Critical |
| Signalling window | 2,000 blocks | Consensus change |
| Signalling threshold | 1,500 blocks (75%) | Consensus change |
| Snapshot challenge window | 48 hours | Critical |
| Guardian pause limit | 14 days, auto-expire | Critical |
