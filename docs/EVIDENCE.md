# Evidence rules

| Label | Meaning |
| --- | --- |
| Verified | Reproducible chain state or reviewed code at a stated checkpoint |
| Supported | Consistent with several evidence points, subject to named limits |
| Technically plausible | Mechanism could occur; evidence does not show that it did |
| Unproved / incorrect | Absent evidence, invalid inference, or contradiction |

Funds movement: tx hash + decoded receipt.
Administration: contract + slot or ABI + the tx that used it.
Fork: first divergent block and both state roots, not chain ID alone.
Identity: signed message or authenticated linkage.
Miner consent: signalling window and the software rule that was signalled, not later list rows.

An explorer screenshot is a view of one RPC.
